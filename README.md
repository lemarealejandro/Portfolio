## 🚀 Ejecución Local

Para levantar el portafolio en tu máquina local sin dependencias externas:

```bash
# Con Python 3
python3 -m http.server 3000

# O con npx serve
npx serve .
```

Abre tu navegador en `http://localhost:3000`.
